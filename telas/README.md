# Biblioteca de telas do Smatch

Capturas do app para uso do marketing. **Dados de demonstração**: a "Arena Demo" e os jogadores, turmas, desafios e
torneios locais são fictícios. Duas pessoas reais aparecem com foto, com autorização delas: o perfil do **Leandro Silva**
é a conta que tira as fotos (canto das telas e "Meu cartão") e o do **Vicente Brusadelli** é o cartão do Match, o card
de perfil e o primeiro coringa. A ficha de jogador dos dois é a real; os jogos, pontos, rankings, torneios e a chamada
de coringa em que aparecem são encenados. As telas de ITF mostram dados públicos da ITF.

- Última captura: **2026-11-13** (pasta `2026-11-13/`)
- Versão do app: commit `fa4d884f (2026-11-12)` do repositório Leandro1799/smatchbeach
- Formato: PNG 1170×2532 (iPhone 390×844 em 3x), modo escuro, sem barra de status do sistema
- Mapa de funcionalidades (o que cada tela faz, para quem, preços e status): [FUNCIONALIDADES.md](FUNCIONALIDADES.md)
- Para gerar de novo: `scripts/capture-screens/` no repositório do app (ver o README de lá)
